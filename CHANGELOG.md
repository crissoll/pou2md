# Changelog

All notable changes to `pou2md` are documented here.

## [0.1.0] - 2026-10-07

Initial public release.

### Added

- Convert TwinCAT 3 `.TcPOU` files to Markdown with Mermaid diagrams.
- Support for CFC, FBD, LD, and ST implementations.
- Class diagram generation from IEC 61131-3 declarations.
- Recursive directory conversion and unified Markdown output.
- Individual output files with optional copied folder structure.
- Watch mode with polling, debounce, retries, parse-error recovery, and locking.
- TOML configuration files, manifests, stale-output cleanup, and dry-run mode.
- Structured text/JSON logging, exclusions, output validation, and atomic writes.
- CLI entry points through `pou2md` and `python -m pou2md`.
